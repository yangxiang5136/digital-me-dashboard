# Digital Me — dashboard

The public, Vercel-deployed surface for **Digital Me**, a multi-agent personal AI system.
The engine lives in a separate repo: [yangxiang5136/digital-me](https://github.com/yangxiang5136/digital-me).

## What's here

| Page | What it is | Source |
|---|---|---|
| [`index.html`](index.html) | A clean, static **architecture showcase** — agent topology + the system's structure. | hand-authored |
| `dashboard.html` | The **live CEO dashboard** — current system state, drawn from the memory bus. | auto-generated by the Interface Agent |
| `news.html` | The **news report** — the latest curated digest. | auto-generated by the Interface Agent |

## The system in one breath

Digital Me is a set of specialized agents that **capture, reason over, and deliver** a
person's memory, coordinating through a single shared bus (`my-memories`). No agent talks
to another directly — the bus is the contract.

| Agent | | Role |
|---|---|---|
| Memory agent | 🐘 | captures & scores memories (Telegram + HTTP intake) |
| Connection mapper | 🕸️ | scores memories and weaves connections across the corpus |
| Information agent | 🦉 | two-tier news pipeline + editorial delivery |
| Interface agent | 🦎 | renders system state into views (this site, dashboard, news) |
| Strategist | 🦊 | conversational thinking partner + daily system pulse |
| Learning agent | 🐙 | compiles memories into structured knowledge |

Flow: **intake → bus → reason → deliver.**

## How it deploys

Pushes to `main` auto-deploy to Vercel.

- `index.html` is **static and hand-maintained** — the architecture showcase visitors land on.
- `dashboard.html` and `news.html` are **regenerated and pushed by the Interface Agent** as
  the memory bus changes, so they never overwrite the showcase.

Runtime models: DeepSeek V4 (see the engine repo's `model-config.yaml`). Hosting: Railway
(agents) + Vercel (this surface).
