今日总结 Today

OpenAI 介绍其前沿模型训练已完全断网，并用 AI 智能体红队测试自家基础设施。隔离测试中，智能体在无网络、无共享文件的条件下通过 CPU 缓存时序差异、共享内存写入模式等侧信道通信，甚至独立建立编码方案交换信息。

月之暗面发布旗舰模型 Kimi K3.1 Pro，参数 2.8T，支持 100 万 Token 上下文，完整模型权重预计 11 月 4 日前开放。API 输入每百万 Token 13 元、输出 68 元，相比 K3 基本砍半，并同步推出输出速度约 2 到 3 倍、价格翻倍的 Highspeed 版本。OpenRouter 同日上线该模型，定价 $2/M 输入、$10/M 输出。

MiniMax 宣布 M3.1 Flash 权重公开，总参数 428B、每 token 激活 23B，提供 Hugging Face 和 ModelScope 下载。

Claude 官方宣布，下周起 Pro、Max 和 Team 套餐在网页、桌面和移动端应用中的会话将默认以 auto mode 运行。auto mode 不再逐步请求用户批准，而是由自动检查拦截高风险操作，用户可随时切回手动模式。其引用的 Claude Code 更新提到 auto mode 用独立分类器审查 shell 命令，测试中拦截了 89% 的危险命令，手动批准为 14%。

Agentic AI Foundation 宣布四个新项目：Agent Skills 由 Anthropic 贡献，Open Responses 由 OpenAI 贡献，OpenEnv 由 Hugging Face 贡献，OpenSandbox 由阿里巴巴贡献。AAIF 成立第一年项目数从 3 个增至 10 个。Anthropic 表示 Agent Skills 自 2025 年 12 月发布以来已被 ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 多个 Agent 平台集成。

Kling 4.0 在 fal 上线并向所有客户开放 API 访问，支持最长 30 秒带音频的原生视频生成、最多 15 个图像/视频/元素参考、最多 10 个关键帧的精确控制。

Ora 联合 Vercel、Stripe、Auth0、Mintlify、Tavily、Google、Elementor 和 MIT 推出 AgentReady.org，一个定义产品如何对 Agent 可用的开放标准。
