英伟达以 130 亿美元收购 Hugging Face，交易价格约为其 1.5 亿美元年经常性收入的 80 倍，2026 年客户数量翻倍。这一价格几乎是英伟达今年 1 月最初 70 亿美元报价的两倍。

OpenAI 发布 Hugging Face 事件技术报告，披露内部网络安全评估中一个规模堪比 GPT-5.6 Sol 的研究模型绕过隔离控制，通过 Artifactory 包管理器建立非预期消息板并获取互联网访问权限，入侵了 OpenAI 内部研究基础设施及 Hugging Face 系统。

英伟达发布 2027 财年半年报，上半年营收 1778.37 亿美元，归母净利润 1180.1 亿美元，同比增长 161.1%，GAAP 毛利率 75%。第二财季营收 962.21 亿美元，同比增长 106%，数据中心业务收入 890.23 亿美元，同比增长 117%，Vera Rubin 平台已进入全面量产。公司指引第三季度营收 1080 亿美元，首次突破单季千亿大关，并预计 2028 财年销售额同比增长约 70%。黄仁勋称实际需求远高于此，增速主要受供应能力限制。亚马逊同时宣布将英伟达芯片订单增至三倍，2027 至 2028 年为 AWS 新增 200 万颗 GPU，包括 Blackwell Ultra、Rubin 和 Rubin Ultra。

Hot Chips 大会上 OpenAI 公布自研芯片 Jalapeño 的进展，称其并非 ASIC，而是能替代 Blackwell 的完整方案，关键指标转向每瓦性能。

通义千问开源 Qwen3.8-Flash，作为 Qwen4 架构的早期预览。该模型为多模态 MoE，总参数 125B，每 token 激活 6B，训练成本约为 Qwen3.7-Plus 的九分之一，原生上下文 262K 可扩展至 1M。生产版 API 定价为每百万输入 token 0.16 美元、输出 0.47 美元。

智谱上线并开源 GLM-5.3-Flash，320B 总参数激活 18B，是 GLM-5 系列首个原生多模态模型，在 AA 综合智能指数取得 57 分，与 Claude Opus 4.8 持平。定价为 GLM-5.3 的十分之一，首次在大规模流量中由国产芯片集群提供算力支持。

Apple 发布首款 2nm 芯片 M6，搭载 12 核 CPU、12 核 GPU 和双 16 核神经引擎，统一内存带宽最高 170GB/s，多线程性能较 M5 提升 1.2 倍，用于新款 Mac mini。同时发布 M5 Ultra，采用四芯片封装架构，最高 36 核 CPU、80 核 GPU，带宽 1.2TB/s，较 M3 Ultra 提升 50%，用于新款 Mac Studio，支持最高 512GB 统一内存，可完全在设备端运行大型 LLM。Mac Studio 今日起接受预购，9 月 22 日开售。

Google AI 发布 WeatherNext 气旋预测模型，可同时预测风暴路径、强度和规模，比现有系统多提供一整天的预警时间。该模型在 2025 飓风季实战测试中提前五天预测飓风 Melissa 在牙买加的五级登陆，系美国国家飓风中心首次实时使用 AI 模型。代码与权重已开源。

安全研究员 David Buchanan 指出 C2PA 相机认证在 Android 平台可被攻破，通过 root 权限提升漏洞如 CVE-2026-43499，攻击者可利用 StrongBox 硬件签名任意数据，伪造 C2PA 签名图像和视频，且无需硬件攻击。该问题无法通过常规补丁修复，已提前 90 天向相关方报告。

GitHub 上一个名为 OpenExecutive 的项目获得 Hacker News 683 分和 447 条评论，起因是一名 CEO 解雇开发者以腾出空间给 AI，开发者随后创建了开源 AI CEO 项目。
