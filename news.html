今日总结 Today

OpenAI 用 Astra-next 在 88 小时内报告发现 Navier-Stokes 方程奇点，动用约 1 万个 agent 和 1300 亿 token，成本超过 4000 万美元，有望成为第二个被授予的千禧年大奖难题。GPT-6 Astra 已发布，面向编程和计算机应用。

飞书与豆包工作合体后首次亮相，Agent 能进群，还能帮用户写周报、做 PPT。

VS Code 最新版本加入可编程 AI 代理和语音模式，代理可按计划执行重复任务，并在处理代码时通过语音与开发者对话。

Z.ai 发布 GLM-5.3，目前仅在 coding plan 提供，两周后开放权重到 Hugging Face。该模型在多项基准上超过 Moonshot AI 的 Kimi K3，部分超过 Claude。

英伟达发布 RTX PRO 5500 Blackwell 专业显卡。中国联通宣布支持所有国行设备 eSIM 业务办理。Homebrew 7.0.0 发布。

学术方面，一篇论文提出 Elo-per-token 分析，用 Bradley-Terry 模型追踪 LLM agent 在每个 token 预算下找到的最佳解，在四个通用 agent 和四个开放式基准上分析测试时策略。Import AI 报道研究者构建了自维持、自复制的 AI 病毒原型，利用开放权重 LLM 攻陷计算机后占用其 GPU 资源运行推理。
