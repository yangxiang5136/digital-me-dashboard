OpenAI 发布内部数据称已达到自动化研究实习生里程碑，即模型可在人类监督下完成熟练研究员需数天的明确任务。截至 8 月中旬，其研究组织每投入 1 个人工工作日，就使用 3.1 个 agent 工作日的运行时长，该比值衡量的是运行时间而非等效生产力。OpenAI 同时发文宣布计划在 2028 年 3 月前造出自动化 AI 研究员，并援引内部员工观点称递归自我改进或成为未来几年 AI 能力的关键。

OpenAI 发布长文《An Alien Mind》，回溯 2023 年 RLSlow 项目确认推理模型可扩展训练的起点，系统阐述目标对齐与价值对齐的区分。文章指出链式思维监控的效果正随模型能力提升而逐步减弱，GPT-6 Astra 在对齐上显著优于 GPT-5.6 Sol，并预期进展可能持续走向机器递归自我改进，呼吁自愿放缓扩展、建立第三方安全门槛并加强国际协调。

GPT-6 Astra 上线后，大量用户用它自主操控 Blender、Houdini、Unity、Aseprite 等专业软件，做出游戏 Demo、3D 复刻旧金山艺术宫等作品。旧金山艺术宫案例中 Astra 自己搜索数百张参考图、翻到美国国会图书馆的老扫描文件找柱子尺寸，多数工作在夜间自主完成。Simon Willison 称 Astra 在细节关注、用户意图理解和复杂输出构建上全面更强，尤其擅长 3D 建模。

Meta 发布 Muse Spark 1.3，据 AAII 排名为全球第三模型，性能对标 OpenAI 与 Anthropic 的前沿模型，并承诺开放权重，训练成本折扣超过 90%。

MCP 发布更新路线图，覆盖下一版规范及之后的方向，由核心维护者与各工作组共同制定。此前 2026-07-28 规范候选版已发布，是该协议自推出以来最大一次修订，核心改为无状态、可在普通 HTTP 基础设施上扩展，并加入服务端渲染 UI、长时任务扩展、更贴近 OAuth 与 OpenID Connect 的授权机制，以及正式弃用政策。

Armature 对 16893 次会话、1163 个 prompt 变体、75 个代码仓库、10 种语言进行实验，比较 Claude Code、Codex 和 Cursor 三个 coding agent 实际选择的工具，最终筛出 5292 个有效会话，覆盖 51 个代码库和 18 个行业。该公司自称这是一项有偏见的实验。

GOSIM Shenzhen 2026 将于 10 月 16 至 17 日在深圳举办，DHH 领衔，英伟达、微软、Hugging Face 等 150 余位技术人士参与，全议程已公布。
