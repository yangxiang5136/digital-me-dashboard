今日总结 Today

OpenAI 发布 Agents API 公测版，把驱动 Codex 的 harness 与基础设施通过单次 API 调用开放给开发者，托管在云端。核心端点为 POST https://api.openai.com/v1/agents/sessions，OpenAI 负责会话、编排、上下文压缩和恢复，应用负责提供工具和决定执行环境。OpenAI 同时在 API 中推出全双工语音模型 GPT-Live-1，可同时听和说，支持将推理和工具调用委派给 GPT-6 Astra 等后端模型，前端语音层定价每分钟 0.05 美元。

安全研究团队 Calif 发布 WeWorm 演示蠕虫，声称是首个 zero-click 跨平台微信蠕虫，通过微信通话在 iOS 和 Android 间传播。受害者无需接听电话或与手机交互，攻击者即可接管微信账号并以受害者身份呼叫其好友逐级扩散。团队称借助 AI 在约两天内找到漏洞并写出首个远程代码执行利用，构建蠕虫又花了一周。演示使用 Pixel 10a 呼叫 iPhone 17e 等三部真机。

Paul Christiano 加入 OpenAI Foundation Board 及 Safety and Security Committee。该委员会负责 OpenAI 安全与安保实践的治理，Christiano 是 Alignment Research Center 创始人。

小米开源工业级目标说话人语音识别模型 CocktailASR-1，针对鸡尾酒会问题，改变任务输入方式：先告诉模型要听谁说话，再让模型只输出那个人的话，而非单纯做降噪。

Simon Willison 发布 Datasette 两个安全补丁版本 1.0a39 和 0.65.4，分别对应 alpha 系列和稳定版 0.65.x 系列。修复由 Sevban Dönmez 报告的问题，Willison 与 Alex Garcia 使用 Claude Fable 5 对 Datasette 进行了大规模审计，建议在公网运行且混合公开与私有表的实例尽快升级。

vlt 1.0 发布，定位为 npm 的无缝替代品，新增分阶段安装、图谱查询与恶意包防护功能。

Google 的 A2A 协议加入 Agentic AI Foundation，diginomica 分析认为未来六到十二个月该组织的重点在规模化和信任两个方向，涉及 agent 系统从试点进入生产的可靠性、day-two 运维，以及 agent 出错时谁担责的问题。

DeepSeek V4.1 Flash 的部署与计费细节继续更新：9 月 14 日中午 12 点起所有发往 v4-pro 的请求将被强制路由到 4.1 Flash 并按低价计费，缓存命中输入降价 7 倍多、输出价格砍三分之二。硅基流动宣布 Day 0 上线该模型，Tencent WorkBuddy 也上线并提供两周免费试用。
