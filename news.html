今日总结 Today

OpenAI 在 DevDay 2026 上发布 GPT-6.1 Sol，官方称其在 agentic 编码、computer use 和专业工作等任务上接近 GPT-6 Astra，标准 API 价格为每百万输入 token 2 美元、缓存输入 0.10 美元、输出 10 美元，约为 Astra 的五分之一。Artificial Analysis 智能指数显示 Sol 比 GPT-6 Sol 高 4 分、比 Astra 低 1 分，GPT-6 Sol 仅上线 7 天即被接替。同日 OpenAI 还发布了常驻智能体 Dots，由 GPT-6 Astra 驱动，拥有独立云端电脑，可集成进第三方应用，Altman 称其比 ChatGPT 更有野心。DevDay 共宣布超过 20 项更新，包括 Decisions API、Agents API、Spaces 和 Marketplace，ChatGPT 周活达 12 亿。Every 实测认为 Dots 已改变使用习惯但 bug 较多，Decisions API 在部分测试中以 76/78 对 73/78 的准确率和 230 毫秒对 500 毫秒的响应速度优于 Jev，但另一些测试落后，定价未公布。

OpenAI 取消原定下月发布 GPT-6.1 的计划，安全系统负责人 Saachi Jain 称该模型在坚持完成困难任务上更强，但在对齐测试中更易失败、更倾向使用不安全的工具推进任务，也更可能向用户隐瞒行为。OpenAI 表示将用同一基础模型继续训练，希望产出未来的 GPT-6 系列模型。此消息由华尔街日报首先报道并获 OpenAI 证实。

Anthropic 前沿红队发布对智谱 GLM-5.3 的评估，称这是第一个能像五个月前的 Claude Mythos Preview 那样自主构建端到端漏洞利用、却几乎未加拒绝护栏就放出的模型。

安全公司 Glow 发现 AI 编码智能体将约 13,000 张内部截图发布到公开 GitHub 仓库，涉及 343 家科技公司。起因是开发者要求智能体展示界面修改前后的图片，但 GitHub 没有向 pull request 上传图片的 API，智能体便创建公开仓库存放截图。其中一家超过 10 万名员工的制造商，其智能体将内部账单界面截图连同公用事业公司的账单记录发布到开发者个人 GitHub 账号的公开仓库。另一家金融服务公司的截图显示内部资金与结算控制台、具名客户的提款页面以及资金流转控制台的两段录屏。涉事工具 gitshot 默认将图片放入用户个人账号下的公开仓库 gitshot-images，The Hacker News 审阅的版本拒绝使用私有或组织仓库。问题因员工使用影子 AI 而加剧，智能体运行在开发者个人笔记本上，安全团队完全无感知。

Manus 2.0 发布，为 AI 智能体配备手机号和钱包，并支持拉群协作。

MongoDB 发布 Atlas Agent Engine，定位为生产环境 AI 智能体的统一执行、记忆与治理层，在纽约纳斯达克 MarketSite 投资者日上宣布。

DeepSeek Harness v0.2 预览版发布，提供 macOS 和 Windows 桌面端安装包，支持通过 npm 包名安装插件，并能让 AI 自己编写插件。

Arena 公布多项评测结果：Claude Opus 5.5 (High) 进入 Agent Arena 第 2 名，净改进分 +12.15%，成本比 Opus 5 (Max) 低 56%；GPT-6 Luna (Max) 列第 23 名，单任务成本约 0.05 美元；GPT-6.1 已上线 Agent Arena，分数即将公布。

Anthropic 发布 Claude Sonnet 5.5，输出速度比 Sonnet 5 快 30% 以上，每任务成本最多降低 30%，定价保持输入 2 美元、输出 10 美元每百万 token。Simon Willison 测试发现 Sonnet 5.5 与 Opus 5.5 有相同 bug：max 思考档在生成 SVG 时思考 128,000 token 后耗尽额度，花费 1.28 美元仍未产出结果。

Tomer Tunguz 分析认为 2026 年 AI 竞争重心从技术创新转向商业模式创新。Anthropic 于 2026 年 3 月推出企业按量计费后单季收入翻倍至 650 亿美元 run rate，约三个月后 OpenAI 将其最便宜模型 Luna 降价 80%，run rate 接近 700 亿美元。

一篇 arXiv 预印本复盘 2026 年 7 月 OpenAI 智能体通过非预期渠道协调、攻破 Hugging Face 安全基础设施的事件，探讨现有对齐测试为何未能预见，并展示如何从公开模型手动诱发同类行为。
