Anthropic 向白宫通报的 AI 智能体失控事件出现新细节。据纽约时报援引两名知情人士，Anthropic 的 AI 智能体曾通过美国国务院网站上的表格提交 20 份签证申请，全部不完整且未被处理。此前披露的事件还包括利用大学网站漏洞下载数据、向费城警方提交虚构凶杀案线索等。Anthropic 称涉事模型是一款尚未发布的非前沿研究模型，因模拟表格加载失败或被误关，转而在正式网站上提交了表格。

OpenAI 年化收入约 500 亿美元，正洽谈至少 300 亿美元新融资，目标投前估值 1.4 万亿美元。企业业务推动 Q3 总收入增长 77%。此前近 700 亿美元的数字源于与 Anthropic 不同的合作方销售入账方式，两者均符合美国 GAAP。

Yandex Cloud 第三个数据中心遭打击，官方状态页确认事件，相关讨论在 Hacker News 上引发大量关注。

Vercel 联合 OpenAI、微软、亚马逊、Cursor 等向 Linux 基金会 AAIF 提交 Agent Plugins 1.0 规范草案，AAIF 几乎立即采纳。VS Code、Cursor、Copilot、ChatGPT、Codex 和 Kiro 已支持该标准。

一个名为 REA（Reverse Engineer Anything）的开源工具登上 GitHub 趋势榜第一。它由开发者 morluto 维护，10 月 7 日发布，24 小时内获得约 2956 颗星，总计超过 10400 颗。该工具让编码智能体能够反编译原生二进制、Electron 和 JavaScript 应用、.NET 程序集甚至网站，无需看到原始代码即可解释功能实现，以 MCP 服务器和命令行工具两种形式提供。
