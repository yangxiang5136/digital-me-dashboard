今日总结 Today

谷歌发布 Gemini 3.7 Flash，距 3.6 Flash 仅三周。该模型在 DeepSWE v1.1 软件工程评测中取得 65.3%，谷歌称在编码、网页开发及复杂文档处理上较前代有显著提升。年底前以每百万 token 输入 0.75 美元、输出 3.75 美元的特价提供，并已接入 Gemini Spark 个人 AI 代理服务及 GitHub Copilot 等开发环境。

Block 发布 Berd，一个 Apache 2.0 许可的本地桌面代理工作区，支持跨模型和 harness 运行，对话历史存储在本地。目前 GitHub 上已到 0.6.2 版本，有 91 位贡献者，提供 macOS、Windows、Linux 免费构建。Block AI 能力负责人 Brad Axen 表示桌面优先是因为其价值来自直接操作本地项目、文件、工具和代理。

Amazon Bedrock AgentCore Payments 正式可用，让代理能够安全自主地进行交易。Anchor Browser 已集成该功能，用于在网页代理工作流中解锁付费内容，内置支付限额。

OpenRouter 上出现一个名为 Ox Alpha 的 stealth 模型，Hacker News 讨论热度较高，但公开信息有限。

OpenAI Codex 在 AWS Bedrock 上存在一个计费 bug，导致费用被收取 10 倍，相关 issue 已在 GitHub 上公开，Hacker News 上有 137 分和 53 条评论。

Wiz 与 GitHub 就 Snowflake 漏洞事件出现分歧。Wiz 称 Red Agent 自主发现并利用了 Snowflake 公开仓库中的 GitHub Actions 漏洞，并指 Copilot Autofix 是批准该代码变更的合著者。GitHub 内部审查后表示，导致漏洞的代码由人类编写，未经 Copilot 审查或贡献。

Cursor 的 Origin 平台补充披露了代理代码的结构化元数据追踪功能：每行由 AI 代理注入的代码都带有审计轨迹，记录所用模型、提示逻辑和上下文窗口配置。Origin 定位为 GitHub 之上的一层，通过双向同步与 GitHub 集成，而非直接替代，企业可通过管理员设置退出 beta。

Unite.ai 文章讨论 AI 在遗留代码现代化中的回报，主张不直接让代码生成工具重写旧系统，而是先用 AI 代理梳理十几套应用之间的连接关系，提取嵌入在逻辑中但从未被记录的业务决策，把机构知识固化为可查询的上下文。文章称这一做法与 Anthropic 等供应商公开记录的指导方向一致。
