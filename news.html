亚利桑那州上诉法院裁定，在一起过失杀人案量刑中使用的 AI 生成受害者视频带有不当情感分量，罪名维持但刑期须重新考虑。

Claude Code 推出云端会话功能，每个任务在独立 VM 上运行，仓库克隆到新分支，可从网页、手机、桌面、终端和 Slack 启动并跟踪，完成后产出可转 PR 的分支，Pro、Max、Team、Enterprise 计划不额外收费。

Reflection 发布 Beam 开源模型，参数规模 501B，激活参数 23B。该模型将自己与 Inkling、Nemotron 和 GLM 5.2 对比，但 SOTA 的 GLM 5.3、Kimi K3、Qwen 3.8 Max 和 DeepSeek V4.1 Flash 普遍领先。

CopilotKit 发布 AG-UI 1.0 规范，用于标准化 AI 智能体与用户界面应用的连接方式，已被 Google、Microsoft、Amazon 和 Oracle 采用，并获 LangChain、Mastra 和 Anthropic 的 Claude 等框架支持。

Aiyo 发布 AEAP 执行授权协议首个公开草案，定位为自主意图与后果性执行之间组合边界的授权协议，包含预执行授权、可移植加密回执和独立验证机制，规范以 CC BY 4.0 发布。

SK AX 推出面向无编程背景员工的 AI 智能体开发培训项目 Bootcamp Vibe，采用自然语言描述功能的 vibe coding 方式，目标是让业务人员自行设计和构建所需智能体。
