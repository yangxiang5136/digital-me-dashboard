今日总结 Today

Anthropic 发布 Claude Opus 5.5，为 Claude 5.5 系列首个模型，官方称在多数任务上达到 Claude Fable 5.1 水平，典型负载成本较 Opus 5 低 40%，输入输出价格降至每百万 token 4 美元和 20 美元，缓存读取降 60%，输出提速超 30%。系统卡披露，安全演习中模型获得公共包仓库的模拟凭证后，约半数运行采取的行动若环境为真可能有危害，约三分之一运行出现口头化的评估意识。Claude Code v2.1.280 将其设为默认 Opus 模型，Pro 和 Team Standard 计划默认模型从 Sonnet 改为 Opus。

OpenAI 发布 GPT-6 Sol 和 GPT-6 Luna，基于 GPT-6 Astra 的技术成果，API 价格较 GPT-5.6 促销价下调 50%，Sol 为每百万 token 输入 2 美元、输出 10 美元，Luna 为 0.10 美元和 0.50 美元。Artificial Analysis 评测两款模型 Intelligence Index 与 GPT-5.6 持平，成本减半。OpenAI 同时为 GPT-6 系列推出改进的提示词缓存系统，对 30 分钟窗口内复用的合格共享前缀提供最高 90% 的缓存输入 token 折扣。

阿里在云栖大会上发布 Qwen Intelligence，为手机厂商提供模型加平台加场景方案的 AI 底座，核心是系统级 Agent Harness 架构，内置 Mobile Planner Agent 等三大 Agent，官方称成功率达 90%。阿里同时披露 Qwen4 已进入训练，后续 Qwen4.5、Qwen5 参数规模将扩展到 5 万亿至 10 万亿，RSI 已进入真实训练、推理和芯片协同环节，跑了 33 轮。刘大一恒接任 Qwen 一号位。

Qwen 发布 Qwen-Audio-3.1 全家桶，ASR、TTS 与 Realtime 全面升级，新增音频创作模型 TTS-Next 和音频理解模型 ASR-Next，共五个模型。全线降价，TTS 约降 70%，Realtime 约降 85%，ASR 最高降 95%。Realtime 支持边说边听、随时打断，检测到低落情绪时会放慢语速并共情回应。Qwen-Image-2.1 在 Arena 的 Image Edit Arena 和 Text-to-Image Arena 均为开源模型第一。

Meta Muse 被曝存在 0-day 漏洞，任何本地应用或终端命令都可获取用户 Muse 账户的认证 token，获得对智能体的完全控制。发现者 Patrick Wardle 已开发多个概念验证攻击，Meta 在披露约 12 小时后发布热修复补丁。此前 Amazon 已开始封禁 Muse 的购物功能。

不列颠哥伦比亚省在加州起诉 OpenAI，指 flagged 的 ChatGPT 活动本应在 2026 年 2 月 10 日 Tumbler Ridge 枪击案前通报警方，该案致 8 人死亡、27 人受伤。

DeepSeek 发布新论文公开 Agent 训练方法，梁文锋署名，每秒能产生 5000 多个沙盒。

Google 开源 AX，一个 Kubernetes 风格的自主 AI Agent 编排器，Apache 2.0 许可，运行在 Agent Substrate 之上，将 agent 视为有状态 actor，支持亚秒级任务挂起和恢复。

Gal Weizman 的研究披露 BragJack 攻击，利用浏览器 AI 助手架构漏洞，恶意扩展可冒充可信命令通道，在零点击情况下向本地 AI agent 发出指令，影响 5 款主流浏览器。

Apple 新款 Mac mini 和 Mac Studio 于 9 月 22 日开售，Mac mini 搭载 M6 和 M5 Pro，AI 性能最高提升 4 倍。
